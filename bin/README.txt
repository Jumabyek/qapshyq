This folder holds the 7-Zip engine that does the real archive work.

  Windows: 7z.exe + 7z.dll    (scripts\setup_windows.bat puts them here)
  macOS:   7zz                (scripts/setup_mac.sh puts it here)

7-Zip is made by Igor Pavlov - https://www.7-zip.org
License: GNU LGPL + "unRAR license restriction" (see 7-Zip-License.txt).
The RAR code may NOT be used to create RAR archives; Qapshyq only extracts RAR.
