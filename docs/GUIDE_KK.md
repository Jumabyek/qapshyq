# Qapshyq: толық нұсқаулық (қазақша)

## 1. Mac-та іске қосу

1. python.org/downloads/macos сайтынан **Python 3.12** нұсқасын жүктеп, орнатыңыз.
2. `qapshyq` папкасын ашып, **`run_mac.command`** файлын тауып, тышқанның оң жақ батырмасымен басып, **Open** таңдаңыз.
   - Бірінші рет Mac «бұл файл белгісіз әзірлеушіден» деп ескерту береді. Сонда қайтадан **Open** басыңыз.
   - Бірінші іске қосылғанда скрипт қажетті құралдарды өзі орнатады: PySide6 кітапханасын және 7-Zip қозғалтқышын (ресми 7-zip.org сайтынан). Бұл 1–2 минут алады.
3. Qapshyq терезесі ашылады.

Терминал арқылы іске қосу:

```bash
cd ~/Downloads/qapshyq
bash scripts/setup_mac.sh      # бір рет орындалады
./run_mac.command
```

## 2. Windows-та іске қосу

1. python.org сайтынан **Python 3.12** нұсқасын орнатыңыз. Орнатқанда **«Add python.exe to PATH»** дегенге белгі қойыңыз.
2. **`run_windows.bat`** файлын екі рет басыңыз. Бірінші іске қосылғанда скрипт бәрін өзі орнатады.

## 3. Тексеру тізімі

| Не істейсіз | Не болуы керек |
|---|---|
| ZIP файлын терезеге сүйреп тастаңыз | Ішіндегі файлдар кесте болып шығады: атауы, көлемі, күні, түрі |
| **Extract all to …** батырмасын басыңыз | Архивтің жанында жаңа папка пайда болады, «Open folder» батырмасы шығады |
| 2 файлды таңдап, батырманы басыңыз | Тек сол 2 файл шығарылады |
| Архивтегі файлды екі рет басыңыз | Файл бүкіл архивті шығармай-ақ ашылады |
| Іздеу жолына «jpg» деп жазыңыз | Тек JPG файлдары көрінеді |
| Папканы терезеге сүйреп тастаңыз | «Create archive» терезесі ашылады |
| 7Z + Maximum + құпиясөз таңдап, **Create** басыңыз | .7z архиві жасалады |
| Сол архивті ашыңыз | Құпиясөз сұралады, қате құпиясөз енгізсеңіз «not correct» деп жазылады |
| Үлкен файлды сығып жатқанда **Cancel** басыңыз | Процесс бірден тоқтайды, жартылай жасалған файл қалмайды |
| Кез келген .txt файлын .zip деп атын өзгертіп ашыңыз | «This file is not a supported archive» деген түсінікті хабар шығады |
| **☀ Light / 🌙 Dark** батырмасын басыңыз | Тақырып ауысады, келесі жолы ашқанда да есте қалады |

Автоматты тесттерді іске қосу:

```
.venv/bin/python -m unittest discover -s tests -v              (Mac)
.venv\Scripts\python -m unittest discover -s tests -v          (Windows)
```

Нәтижеде 14 тест «OK» болуы керек.

## 4. Код қалай құрылған

```
main.py                       бағдарламаны іске қосу
app/engine/                   архивпен жұмыс (интерфейс жоқ)
  sevenzip.py                 7-Zip-ті табу, іске қосу, прогресс, тоқтату
  archive.py                  list / extract / create функциялары
  models.py                   деректер класстары (ArchiveEntry, ArchiveInfo, CreateOptions)
  errors.py                   7-Zip қателерін адамға түсінікті хабарға айналдыру
app/workers/task_worker.py    ауыр жұмысты фондық ағында (thread) орындау
app/ui/                       терезелер мен виджеттер
  main_window.py              бәрін біріктіретін басты терезе
  drop_zone.py                бастапқы экран (сүйреп тастау)
  archive_view.py, file_tree.py  архив ішін көрсету
  create_dialog.py            архив жасау терезесі
  password_dialog.py          құпиясөз терезесі
  progress_panel.py           прогресс жолағы және Cancel батырмасы
  theme.py, icons.py          түстер және белгішелер
```

**Негізгі идея:** интерфейс 7-Zip-пен тікелей жұмыс істемейді. Ол тек `archive.py` ішіндегі функцияларды шақырады. Ал `archive.py` тиісті 7-Zip командасын құрастырады, мысалы:

```
7z x archive.zip -o"папка" -p... -bsp1
```

Сосын 7-Zip-тің жауабын оқиды. Ауыр жұмыс бөлек ағында орындалады, сондықтан терезе ешқашан қатып қалмайды.

## 5. Орнатқыш жасау (.exe / .dmg)

### А) Ең оңай жол: GitHub Actions (компьютеріңізге ештеңе орнатпайсыз)

1. github.com сайтында тіркеліп, **New repository** → `qapshyq` деп жаңа репозиторий ашыңыз.
2. Жоба файлдарын жүктеңіз. Мысалы, GitHub Desktop бағдарламасы арқылы немесе терминалда:
   ```bash
   cd qapshyq
   git init && git add . && git commit -m "Qapshyq 1.0.0"
   git branch -M main
   git remote add origin https://github.com/АТЫҢЫЗ/qapshyq.git
   git push -u origin main
   ```
3. GitHub сайтында **Actions** → **Build installers** → **Run workflow** басыңыз.
4. 10–15 минуттан кейін нәтиже бетінің төменгі жағында **Qapshyq-Windows** (Setup.exe) және **Qapshyq-macOS** (.dmg) файлдары пайда болады.
5. Ресми шығарылым (Release) жасау үшін нұсқа тегін жіберіңіз: `git tag v1.0.0 && git push origin v1.0.0`. Сонда екі файл да **Releases** бетіне автоматты түрде қосылады.

### Ә) Windows компьютерінде қолмен жасау

1. jrsoftware.org/isdl.php сайтынан **Inno Setup 6** орнатыңыз.
2. `scripts\build_windows.bat` файлын іске қосыңыз.
3. Нәтиже: `dist\Qapshyq-Setup-1.0.0.exe`

### Б) Mac-та жасау

Finder-де **`build_mac.command`** файлын екі рет басыңыз (немесе Терминалда `bash scripts/build_mac.sh`).
Нәтиже: `dist/Qapshyq.app` және `dist/Qapshyq-1.0.0-mac.dmg`.

**Жаңа нұсқа шығарғанда** нөмірді екі жерде өзгертіңіз: `app/__init__.py` ішіндегі `__version__` және `installer/qapshyq.iss` ішіндегі `AppVersion`.

**Қолтаңба туралы.** Қолтаңбасыз Setup.exe файлын ашқанда Windows «Windows protected your PC» деп ескертеді. Пайдаланушы **More info → Run anyway** басуы керек. Бұл ескертуден құтылудың жолдары:
- Microsoft Store арқылы MSIX ретінде тарату (тегін қолтаңба);
- ашық бастапқы кодты жобаларға тегін қолтаңба беретін қызметтер, мысалы SignPath Foundation;
- ақылы code signing сертификатын сатып алу.
